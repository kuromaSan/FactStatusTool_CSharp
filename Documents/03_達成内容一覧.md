# FactStatus 達成内容一覧

## 状態の定義

- **完了**: 実装済みで、対象の自動テストまたは手動確認も完了している。
- **実装済み・要確認**: コードは存在するが、今回の計画では動作確認が未完了である。
- **未着手**: 実装または仕様確定をこれから行う。

## リリースまでの達成目標

### 基盤

- [ ] 開発環境でビルド、テスト、UI起動ができる
- [ ] データモデルとID・関連ルールをテストで保証する
- [ ] JSONの保存・再読み込みでデータが同一に復元される

### SQLite永続化

- [ ] `IFactStatusSqliteRepository` とSQLite実装を追加する
- [ ] DB初期化・スキーマバージョン確認・移行を実装する
- [ ] `FactStatusMain.LoadSqliteAsync` でSQLiteからAggregateを復元する
- [ ] `FactStatusMain.SaveSqliteAsync` でAggregateをトランザクション保存する
- [ ] エンティティ・属性・親子リンク・グループリンクのSQLite往復テストを追加する
- [ ] 保存失敗時にDBの既存データが変更されないことをテストする

### Markdown連携

- [ ] Markdown単体の読み込みを実装する
- [ ] Markdownルートからツリー全体を読み込む
- [ ] Markdown保存後に読み込み可能であることを確認する
- [ ] 既存の `Documents/` サンプルとの互換性を確認する

### 操作機能

- [ ] エンティティの作成・編集・削除をUIから実行できる
- [ ] 移動・複製・グループ化をUIから実行できる
- [ ] 削除・不正な関連付けに対するエラー表示を実装する
- [ ] 未保存変更の保存確認を実装する

### 可視化・集計

- [ ] 親子ツリーとグループを画面上で参照できる
- [ ] 成功・失敗と件数を表示できる
- [ ] 失敗内容の一覧を確認できる

### 品質

- [ ] 各ユースケースの正常系・異常系テストを追加する
- [ ] 入出力の往復テストを追加する
- [ ] 手動受入確認を行い、既知の制約を記録する
