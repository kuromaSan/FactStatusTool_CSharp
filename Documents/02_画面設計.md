# FactStatus 画面設計

## 目的

FactStatus のエンティティをID単位で閲覧・編集し、関連する情報へ素早く移動できる画面を定義する。初期表示では1つの中央メインUIを表示し、必要に応じて右側または下側へ分割して複数の内容を同時に参照する。

## メニューバー

ウィンドウ最上部には、Visual Studio Codeと同様に常時表示するメニューバーを配置する。メニューバーは画面全体に作用する操作を集約し、ペイン固有の操作とは分離する。

| メニュー | 初期項目 | 役割 |
| --- | --- | --- |
| ファイル | 開く、保存、名前を付けて保存、終了 | データの読込・保存とアプリケーション操作 |
| 編集 | 元に戻す、やり直す | 直近の編集操作の取り消し・再実行 |
| 表示 | 左サイドバー表示、分割表示の管理 | 画面表示の切替 |

`開く` と `保存` はファイルメニューから実行する。保存はデフォルトで自動保存するが、手動保存・名前を付けて保存も利用可能とする。

## 初期状態

- 左サイドバーと中央メインUIを表示する。
- 中央メインUIは選択中のIDに対応する内容を表示する。選択がない場合は、読込方法または対象の選択を案内する空状態を表示する。
- ウィンドウ最上部には、ファイル・編集・表示のメニューバーを配置する。
- 親階層メニューは、中央メインUIの上部に配置する。
- 親階層メニューの右端には、読込ボタン、書き込み可切替ボタン、右に分割ボタン、下に分割ボタンを配置する。
- 初期状態では分割ペインを表示しない。

## 左サイドバー

### 構成

左サイドバーは上から検索・フィルター、ID種別ごとの一覧の順に配置する。

1. 検索・フィルター用の検索バー
2. 主題
3. 達成
4. 証拠
5. 結果
6. 記録
7. 手順
8. 構想

各ID種別は親見出しとして表示し、その直下に該当エンティティを並べる。親子リンクをたどるツリー階層はサイドバー内には作成しない。

### 一覧の表示規則

- 各項目はIDの昇順でソートする。
- 同じID種別の項目は、タイトルを主表示、IDを補助表示とする。
- 検索バーにはID、タイトル、説明を対象として入力語を部分一致で絞り込む。
- 検索結果がないID種別の見出しは表示するが、配下に「該当なし」を表示するか、空の状態にする。
- 項目を選択すると、アクティブな中央メインUIまたは分割ペインにそのIDの内容を表示する。
- 選択中の項目はハイライトし、どのペインに表示されているか分かる状態を表示する。

### 対象外

- Group は初期サイドバーの分類には含めない。Groupの閲覧・編集は、将来の拡張として別の表示方法を定義する。
- Document はルート操作の対象とし、ID種別一覧には含めない。

## 中央メインUI

### 共通表示

中央メインUIは、選択したIDの種別にかかわらず、次の情報を共通して表示する。

- ID
- 種別
- タイトル
- 説明
- 保存状態（未変更／未保存変更あり）
- 親エンティティへのリンク
- 子エンティティおよび関連エンティティへのリンク

表示する種別は、Document、主題、達成、証拠、結果、記録、手順、構想とする。各種別固有の情報は共通情報の下に表示する。

| 種別 | 固有表示内容 |
| --- | --- |
| Document | 配下の主題、ドキュメントの説明 |
| 主題 | 配下の達成・構想、主題の説明 |
| 達成 | 親主題、配下の証拠・手順 |
| 証拠 | 親達成、成功状態、配下の結果・手順・構想 |
| 結果 | 親証拠、引数、アサーション、配下の記録 |
| 記録 | 親結果、日時、確認者、成功状態 |
| 手順 | 親となる達成または証拠、説明 |
| 構想 | 親となる主題または証拠、経験、評価、仮説、抽象化目標、実行目標 |

### 表示・編集モード

- **読み取りモード**: 内容を参照できる。編集項目と保存操作は無効とする。
- **書き込み可能モード**: 内容の編集、作成、削除、保存を可能にする。
- 書き込み可能モードは、各ペイン上部の切替ボタンで切り替える。
- 書き込み可能モードでの変更は自動保存する。保存中・保存済み・保存失敗の状態を画面に表示し、保存失敗時は再試行または保存先変更を選択できるようにする。

## 上部操作

### 中央メインUI上部: 親階層メニュー

- 選択中のエンティティの親IDを、中央メインUI上部のメニューに表示する。
- メニューを選択すると、アクティブペインに親エンティティを表示する。
- 親が存在しない場合は `親階層なし` と無効表示にする。
- 左サイドバーの選択状態も移動先に同期する。
- サイドバーは階層表示ではないが、このメニューにより実際の親子関係をたどれるようにする。

### 親階層メニュー右端: 読込

- ファイルまたはMarkdownルートを選択し、FactStatusデータを読み込む。
- 読込形式はJSON、リレーショナル形式JSON、Markdownを選択できるようにする。
- 読込成功後、左サイドバーを再構築し、初期表示対象を決定する。
- 未保存変更がある場合は、読込前に確認を表示する。

### 親階層メニュー右端: 書き込み可切替

- ボタンは現在状態が分かるラベルとする。例: `読み取り専用` / `書き込み可能`。
- 読み取り専用から書き込み可能への切替は、編集を開始できる状態にする。
- 書き込み可能から読み取り専用への切替は、未保存変更がなければ即時に反映する。未保存変更がある場合は確認を表示する。
- 保存先の指定と実際の保存操作は、書き込み可能モードでのみ利用可能とする。手動保存はメニューバーのファイルメニューから実行する。

## 分割ペイン

### 分割操作

- `右に分割`: アクティブペインの右側に新しいペインを作成する。
- `下に分割`: アクティブペインの下側に新しいペインを作成する。
- 新しいペインは、分割元と同じIDを初期表示する。ただし、独立して別のIDを選択できる。
- 分割後、ユーザーが最後に操作したペインをアクティブペインとする。

### 分割後の操作

- 分割された側のペイン上部には `閉じる` ボタンを表示する。
- `閉じる` を押すと対象ペインだけを閉じ、残ったペインをアクティブにする。
- 自動保存の完了前にペインを閉じる場合は、保存完了を待機するか、閉じる操作を取り消せるようにする。
- 分割できる数の上限は実装時に決定する。初期実装では、操作性を優先して最大4ペインを目安とする。
- 読込・書き込み可切替・選択・親階層移動・分割はアクティブペインに作用する。メニューバーの操作は画面全体に作用する。

## 画面遷移と選択の規則

1. 左サイドバーで項目を選択する。
2. 選択内容をアクティブペインに表示する。
3. 親・子・関連リンクを選択した場合も、アクティブペインに遷移する。
4. 中央メインUI上部の親階層メニューを選択した場合は、実際の親IDをアクティブペインに表示する。
5. 分割後は、各ペインで独立して選択・遷移できる。

## 受入条件

- [ ] 左サイドバーに検索バーと、主題・達成・証拠・結果・記録・手順・構想の分類がこの順で表示される。
- [ ] 各分類配下は親子階層を作らず、ID昇順で表示される。
- [ ] 項目選択時に、アクティブペインへ該当IDの内容が表示される。
- [ ] 中央メインUI上部の親階層メニューで、選択中エンティティの親へ移動でき、親がなければ無効である。
- [ ] ファイル・編集・表示のメニューバーがあり、ファイルメニューから開く・保存・名前を付けて保存を実行できる。
- [ ] 読込と書き込み可能の切替を、中央メインUI上部の親階層メニュー右端から操作できる。
- [ ] 右・下への分割ができ、分割されたペインを閉じられる。
- [ ] 未保存変更がある場合に、読込・遷移・閉じる操作で変更を失わない。
