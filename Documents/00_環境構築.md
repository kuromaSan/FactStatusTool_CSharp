# FactStatus 環境構築

## 目的

FactStatusTool をローカルでビルド・テスト・起動できる開発環境をそろえる。

## 前提

- OS: Windows 10 / 11
- SDK: .NET 8 SDK
- リポジトリ直下の `global.json` により、SDK は `8.0.0` 以降（`latestMajor`）を使用する。
- UI 開発には JetBrains Rider + Avalonia for Rider、または Visual Studio / VS Code を利用できる。

## セットアップ手順

1. [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) をインストールする。
2. リポジトリを取得し、ルートディレクトリで SDK を確認する。

   ```powershell
   dotnet --info
   dotnet --version
   ```

3. 依存パッケージを復元して、ソリューションをビルドする。

   ```powershell
   dotnet restore FactStatusTool.sln
   dotnet build FactStatusTool.sln
   ```

4. ドメイン・UI を含むテストを実行する。

   ```powershell
   dotnet test Tests/FactStatusTest/FactStatus.Domain.Test.csproj
   ```

5. Avalonia UI を起動する。

   ```powershell
   dotnet run --project Scripts/FactStatusUI/FactStatus.UI.csproj
   ```

## IDE 設定

### JetBrains Rider

1. `FactStatusTool.sln` を開く。
2. NuGet パッケージの復元完了を確認する。
3. 次の実行構成を作成または選択する。

   - `FactStatus.UI`: Avalonia UI の起動
   - `FactStatus.Domain.Test`: xUnit テストの実行

`.run/` 配下の共有設定がある場合は、それを優先して利用する。

## 動作確認チェックリスト

- [ ] `dotnet --version` が .NET 8 系を返す
- [ ] `dotnet restore FactStatusTool.sln` が成功する
- [ ] `dotnet build FactStatusTool.sln` が成功する
- [ ] `dotnet test ...` が成功する
- [ ] UI が起動し、メインウィンドウが表示される

## ディレクトリの役割

| パス | 役割 |
| --- | --- |
| `Scripts/FactStatusDomain/` | ドメインモデル、ユースケース、永続化処理 |
| `Scripts/FactStatusUI/` | Avalonia UI |
| `Tests/FactStatusTest/` | xUnit によるテスト |
| `Documents/` | FactStatus が扱うサンプルデータと設計資料 |
