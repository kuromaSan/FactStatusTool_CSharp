# xUnitの設定

## 実装内容

JetBrains Rider では `FactStatusTool.sln` を開き、NuGet パッケージの復元完了を確認する。
xUnit テストを実行するため、`FactStatus.Domain.Test` と `FactStatus.Desktop.Test` の実行構成を作成または選択する。
`.run/` 配下の共有設定がある場合は、その設定を優先して利用する。
