# 親エンティティへ遷移する

## 実装内容

アクティブペイン上部の親階層メニューに親IDを表示し、選択時は親エンティティを表示する。親がない場合は親階層なしを無効表示にし、遷移先にサイドバーの選択状態を同期する。
