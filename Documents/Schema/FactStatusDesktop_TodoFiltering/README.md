# やることのフィルタリングしたものを作りたかった

## 体験

主題、実装、証拠、結果、記録、手順、構想には複数の項目があり、必要な作業を一覧から探す必要がある。

## 評価

すべての項目を一律に表示すると、作業対象を探しにくくなり、関連する項目への移動に時間がかかる。

## 仮説

ID種別ごとの一覧と、ID・タイトル・説明を対象にした検索・フィルターを用意すれば、行いたい作業を絞り込める。

## 抽象目標

利用者が必要な作業対象を素早く見つけられるようにする。

## 実行目標

左サイドバーに検索・フィルターと種別ごとの一覧を表示し、入力語で対象の項目を部分一致検索できるようにする。
