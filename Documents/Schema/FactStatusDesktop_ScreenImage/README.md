# 画面イメージ

## 体験

利用者は、作業対象を絞り込み、選択した内容とその証明・動機を同じ画面で確認する必要がある。

## 評価

一覧、選択中の内容、関連する証拠や構想が離れていると、必要な情報を行き来しにくい。

## 仮説

検索・フィルターを備えた左サイドバーと、選択内容および関連情報を表示する中央ペインを配置すれば、作業対象と根拠を確認しやすくなる。

## 抽象目標

利用者が必要な項目を探し、実装内容・動作の証明・採用理由を連続して確認できるようにする。

## 実行目標

検索・フィルター、項目一覧、選択内容、証拠・構想へのリンクを次の画面イメージで表す。

```text
┌──────────────────────┬───────────────────────────────────────┐
│ 検索・フィルター      │ 選択中の内容                          │
│ [検索___________]    │ ┌───────────────────────────────────┐ │
│                      │ │ 主題 / 実装 / 証拠 / 結果 / 記録   │ │
│ 主題                 │ │ タイトル・説明                     │ │
│ 実装                 │ └───────────────────────────────────┘ │
│ 証拠                 │ 関連情報                             │
│ 結果                 │ ・動作の証明（証拠・結果・記録）     │
│ 記録                 │ ・作る動機（構想）                   │
│ 手順                 │                                       │
│ 構想                 │                                       │
└──────────────────────┴───────────────────────────────────────┘
```
