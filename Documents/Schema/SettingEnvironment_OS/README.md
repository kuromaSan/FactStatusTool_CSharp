# OSに関して

## 体験

開発環境として Windows 10 / 11 を使用する。

## 評価

Windows を前提にすることで、開発者が同じ OS 上で .NET SDK、IDE、およびデスクトップUIを利用できる。

## 仮説

対応 OS を明確にすれば、環境差異によるセットアップ時の問題を減らせる。

## 抽象目標

開発者が共通の環境で FactStatusTool をビルド・テスト・起動できるようにする。

## 実行目標

Windows 10 / 11 を環境構築の対応 OS とする。
