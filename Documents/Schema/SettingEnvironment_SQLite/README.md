# データベースSQLiteの使用理由

## 体験

FactStatusTool ではデータベースとして SQLite を使用することを前提とする。

## 評価

SQLite はアプリケーションに組み込んで使用でき、別途データベースサーバーを準備せずに開発環境を構築できる。

## 仮説

SQLite を採用すれば、開発者ごとのデータベース準備にかかる作業を減らせる。

## 抽象目標

開発環境のセットアップを簡潔にし、すぐに動作確認を始められるようにする。

## 実行目標

開発環境で SQLite を利用できるようにする。
