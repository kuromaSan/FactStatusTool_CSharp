# デスクトップUI Avaloniaに関して

## 体験

Windows、macOS、Linux のいずれでも利用できるデスクトップUI開発環境が求められる。

## 評価

OS ごとに異なる UI フレームワークへ依存すると、開発環境や実装の差異が大きくなる。複数の IDE で扱えることも重要である。

## 仮説

Windows、macOS、Linux に対応し、JetBrains Rider、Visual Studio、VS Code などの IDE で開発できる無償の Avalonia を採用すれば、OS に依存しない UI 開発環境を実現できる。

## 抽象目標

OS に染まらず、開発者が利用する IDE を選べるデスクトップUI開発環境を実現する。

## 実行目標

Avalonia を採用し、JetBrains Rider と Avalonia for Rider、または Visual Studio / VS Code でデスクトップUIを開発・動作確認できるようにする。
