# 動作の証明、それを作る動機を記載したものを作りたかった

## 体験

実装内容だけでは、動作を何で確認したのか、なぜその実装を行うのかを判断できない。

## 評価

動作の証明と採用理由を実装内容から分けて記載すると、確認根拠と実装の背景を追跡しやすい。

## 仮説

証拠・結果・記録を動作の証明として、構想を実装の動機として関連付けて表示すれば、利用者は実装の妥当性を確認できる。

## 抽象目標

実装の内容、確認根拠、採用理由を画面上で関連付けて参照できるようにする。

## 実行目標

選択中のエンティティに関連する証拠・結果・記録・構想へのリンクを表示し、内容を移動して確認できるようにする。
