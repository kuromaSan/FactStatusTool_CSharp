# 主題・実装・証拠・結果・記録・手順・構想の分類

## 体験

FactStatus では、主題に対する実装、実装を確認する証拠、証拠に対する結果と記録、実行手順、採用理由を扱う。

## 評価

これらを同じ内容として扱うと、何を行うのか、何で確認したのか、なぜ行うのかを区別して追跡しにくい。

## 仮説

主題・実装・証拠・結果・記録・手順・構想をそれぞれ独立した分類として扱い、親子関係で関連付ければ、目的から確認記録までを追跡できる。

## 抽象目標

作業の目的、実施内容、確認根拠、採用理由を一貫して管理できるようにする。

## 実行目標

`Subject`、`Achievement`、`Evidence`、`Result`、`Record`、`Todo`、`Schema` のエンティティ種別と親子関係をドメインで管理する。
